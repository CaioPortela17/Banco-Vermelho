# 🏦 Banco Vermelho

Aplicação de Internet Banking desenvolvida para estudos, focada em manipulação do DOM e persistência de dados local.

🚀 **Acesse o projeto online:** https://caioportela17.github.io/Banco-Vermelho/

---

## 📌 Funcionalidades
* **Login e Cadastro:** Autenticação de usuários com validação de e-mail e salvamento via `LocalStorage`.
* **Painel Interativo:** Controle de saldo, alternância de tema e histórico de transações por conta.
* **Simulações:** Realização de Pix, transferências, pagamentos e recargas.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estrutura das páginas (`index.html`, `cadastro.html`, `banco.html`).
* **CSS3:** Estilização responsiva e design moderno.
* **JavaScript:** Lógica de autenticação, validações e manipulação de estado.
* **LocalStorage:** Armazenamento local no navegador para gerenciar usuários, saldos e extratos.

# 🏦 Red Bank

Internet Banking web application developed for studies, focused on DOM manipulation and local data persistence.

🚀 **Try it online:** https://caioportela17.github.io/Banco-Vermelho/

---

## 📌 Features
* **Login & Register:** User authentication with email validation and `LocalStorage` persistence.
* **Interactive Dashboard:** Balance control, theme toggling, and transaction history per account.
* **Simulations:** Pix transfers, bank transfers, bill payments, and mobile recharges.

## 🛠️ Technologies Used
* **HTML5:** Page structure (`index.html`, `cadastro.html`, `banco.html`).
* **CSS3:** Responsive styling and modern design.
* **JavaScript:** Authentication logic, input validation, and state management.
* **LocalStorage:** Browser storage to manage user accounts, balances, and transaction logs.
